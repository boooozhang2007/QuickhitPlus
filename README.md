# QuickHit - 打字游戏

一个 Python 控制台打字竞速游戏，考验打字速度和准确率。

## 游戏规则

- 控制台随机生成一串字母
- 玩家需要在限定时间内正确输入
- 共 3 关，难度递增

| 关卡 | 字符长度 | 时间限制 | 基础分 |
|------|----------|----------|--------|
| 第 1 关 | 4 | 10 秒 | 100 |
| 第 2 关 | 6 | 8 秒 | 200 |
| 第 3 关 | 8 | 6 秒 | 300 |

## 项目结构

```
src/
├── app_start.py    # 程序入口
├── game.py         # 游戏逻辑（随机生成字符串、输出结果）
├── level.py        # 关卡状态
├── level_params.py # 关卡参数配置
└── player.py       # 玩家逻辑（游戏主循环）
```

## 运行

```bash
python3 src/app_start.py
```

Windows 下用 `python src\app_start.py` 即可。程序运行时会依次显示三关的字符串，
在时限内输入正确则进入下一关，输错或超时游戏结束并显示总分。
