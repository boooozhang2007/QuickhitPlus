# QuickHit - 打字游戏

一个 Python 控制台打字竞速游戏，支持单机闯关、无限模式，以及联网的对战匹配、实时在线人数和全服排行榜。

## 游戏规则

- 控制台随机生成一串字母
- 玩家需要在限定时间内正确输入
- 闯关模式共 3 关，难度递增；无限模式关卡不断加长，直到失败

| 关卡 | 字符长度 | 时间限制 | 基础分 |
|------|----------|----------|--------|
| 第 1 关 | 4 | 10 秒 | 100 |
| 第 2 关 | 6 | 8 秒 | 200 |
| 第 3 关 | 8 | 6 秒 | 300 |

## 项目结构

```
├── shared/
│   └── protocol.py    # 通信协议：4 字节长度头 + JSON 消息体
├── server/
│   ├── server.py      # 服务端：多线程 socket，在线表 / 匹配队列 / 排行榜
│   └── auth.py        # 账号系统：哈希表（链地址法）、密码加盐哈希、统计
└── client/
    ├── app_start.py   # 客户端入口（登录、选模式、看在线/排行、发起匹配）
    ├── net.py         # 网络层：后台收消息线程 + 请求/回复配对
    ├── player.py      # 闯关模式
    ├── infinite_game.py # 无限模式
    ├── game.py        # 随机字符串生成、结果输出
    ├── level.py       # 关卡状态
    └── level_params.py # 关卡参数配置
```

## 运行

**1. 先启动服务端**

```bash
python3 server/server.py
```

默认监听 `0.0.0.0:8888`。首次运行会自动在项目根目录创建 `users.json` 保存账号数据。

**2. 再启动客户端**

```bash
python3 client/app_start.py                  # 连本机 127.0.0.1:8888
python3 client/app_start.py <服务器IP> 8888   # 连远程服务器
```

也可以不带参数直接跑单机模式（不需要服务端）：

```bash
cd client && python3 app_start.py   # 需要先改回本地账号模式
```

## 通信协议

`shared/protocol.py` 定义了消息格式，服务端和客户端共用：

- 每条消息 = 4 字节大端长度头 + UTF-8 编码的 JSON 消息体
- TCP 是字节流，不保证一次 `recv` 正好拿到一条消息，所以必须自己定边界
- `recv_msg()` 内部循环读满指定字节数，对端正常关闭时返回 `None`

客户端发请求，服务端回同类型的 `xxx_result`；服务端还会主动推送 `online_count` 和匹配成功的通知。

## 服务端用到的数据结构

| 功能 | 数据结构 | 复杂度 |
|------|----------|--------|
| 账号存储、在线表 | 哈希表（链地址法） | 增删查平均 O(1) |
| 匹配队列 | 双端队列（FIFO） | 入队/出队 O(1) |
| 排行榜 | 排序取前 N | O(n log n) |
| 个人统计的排位 | 二分查找 | O(log n) |
